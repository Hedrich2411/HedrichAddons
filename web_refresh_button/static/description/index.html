Control Panel Refresh Button

Reload the data you are looking at — without reloading the page.

Odoo has no refresh button. Users hit F5, wait for the whole client to boot again and lose their place. This module adds a small refresh button to the control panel that reloads only the current view's records.

Key Features

One click

A refresh button sits next to the pager in every backend view: list, kanban, pivot, graph, calendar and form.

Keeps your place

Breadcrumbs, filters and the current record stay put. Only the data is fetched again.

Nothing to configure

No models, no settings, no security groups. One QWeb template on top of the standard control panel.

How It Works

The button triggers Odoo's own soft_reload client action, the same mechanism the framework uses internally after installing a module. No custom RPC, no page reload, no cache tricks.
